# My Intellectual Journey

> 记录思想，理解世界，修正自己。

A personal journey of thinking, questioning, understanding, and evolving.

## 这是什么？

这里是我的个人思想档案，用 Markdown 持续记录我对世界、社会、技术、商业与自身的观察和思考。

它不是为了证明我永远正确，而是为了留下思考的过程：我曾经相信什么、为什么相信、后来又因为什么改变。

## 内容导航

- [thoughts/](thoughts/) — 日常想法、灵感与尚未成熟的观点
- [observations/](observations/) — 对现实事件、行为和社会现象的观察
- [models/](models/) — 思维模型、分析框架与可复用的方法
- [questions/](questions/) — 值得持续追问、暂时没有答案的问题
- [essays/](essays/) — 经过整理的长文与系统性思考
- [reading-notes/](reading-notes/) — 书籍、文章和其他资料的阅读笔记
- [templates/](templates/) — 记录模板

## 我的记录原则

1. **先求理解，再下结论。** 尽量弄清楚问题本身，而不是急着表达立场。
2. **区分事实与解释。** 明确哪些是可验证的信息，哪些是个人推断或价值判断。
3. **让观点接受检验。** 主动寻找反例、替代解释和自己可能忽略的证据。
4. **允许不确定。** 没有足够依据时，可以保留问题，而不是强行给出答案。
5. **允许改变。** 修改旧观点不是失败，而是理解随着证据和经验更新的结果。
6. **记录过程。** 不只保存最终结论，也保存推理路径、困惑与认知变化。
7. **尊重来源。** 引用他人的观点、数据或原文时，尽可能标注来源。

## 如何使用这个仓库

- 一个文件尽量只讨论一个核心问题。
- 文件名尽量简洁、具体，优先使用日期加主题的形式，例如 2026-10-14-how-i-think.md。
- 暂时不确定归类时，先记录下来，之后再整理。
- 可以在笔记之间使用相对路径链接，逐渐建立自己的知识网络。
- 观点可以不成熟，但要尽量诚实地标明它的成熟程度和依据。

## 一个重要提醒

这是一个公开仓库。请勿提交密码、访问令牌、个人身份信息、私人对话或其他不适合公开的内容。公开记录时，也要尊重他人的隐私与著作权。
